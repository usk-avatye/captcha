# SDK 상호작용 계측 설계

퍼즐의 첫 조작 시간, 풀이 시간, 실패 횟수와 드래그 경로 표본을 수집한다. SDK에서 누적한 값을 기존 인증 서버와 PostgreSQL에 저장한다.

## 측정값

| 필드 | 정의 |
| --- | --- |
| `firstInteractionMs` | 이미지 준비 완료부터 램프를 처음 누른 때까지의 활성 시간. 조작 전에는 `null` |
| `solveMs` | 같은 시작점부터 성공 검증 응답을 받은 때까지의 활성 시간. 성공 전에는 `null` |
| `missCount` | 서버가 `passed=false`로 응답한 드롭 시도 수 |
| `path` | 드래그 좌표 표본. 표본 미선택은 `null`, 선택됐지만 조작 전이면 `[]` |

활성 시간은 모달이 열려 있고 문서가 보이는 동안 누적한다. 닫기와 탭 숨김에서 멈추고 같은 인증을 다시 열면 이어서 잰다. 성공 애니메이션 시간은 풀이 시간에서 제외한다. 드래그 취소와 요청 재전송은 실패 횟수에 더하지 않는다.

이미지 준비 전 인증을 닫아도 발급된 `challengeId`에 시간 `null`, 실패 0의 요약을 연결할 수 있다.

## 경로 표본

`telemetry.pathSampleRate`의 기본값은 `0.01`이다. 인증을 시작할 때 표본 여부를 한 번 결정하고 같은 인증에서는 유지한다. `telemetry.enabled=false`로 요약 수집을 끈다.

좌표는 램프를 누르고 이동하고 놓는 구간에 기록한다. 점마다 `x`, `y`, 활성 경과 시간 `t`와 드래그 시도 번호 `drag`를 저장한다.

- `x`와 `y`는 퍼즐 영역 기준 0~1로 정규화하고 소수점 네 자리로 반올림한다.
- 이동 점은 최소 100ms 간격으로 기록하며 시작점과 끝점을 포함한다.
- 인증당 최대 100개 점을 유지한다. 상한 이후에는 마지막 점을 갱신한다.
- 취소하거나 다시 시도한 드래그는 `drag` 번호로 구분한다.

## 전송

입력 이벤트는 메모리에 누적한다. 매 이동마다 React 상태를 갱신하거나 HTTP 요청을 보내지 않는다.

성공 응답, 모달 닫기, 문서 숨김과 페이지 종료 시 누적 스냅샷을 `POST /api/interaction-summaries`로 전송한다. 페이지 종료 전송에는 `keepalive`를 사용한다. 닫았다 열어도 누적 기록과 전송 순번을 유지한다.

```json
{
  "challengeId": "ch_example",
  "revision": 2,
  "metrics": {
    "firstInteractionMs": 410,
    "solveMs": 1830,
    "missCount": 1,
    "path": [
      {"x": 0.25, "y": 0.6, "t": 410, "drag": 1}
    ]
  }
}
```

새 스냅샷마다 `revision`이 증가한다. 재전송에는 최초 본문과 순번을 그대로 사용한다. 전송 오류가 인증과 고객사 업무 진행을 막지 않도록 비동기로 처리한다.

## 검증과 중복 처리

서버는 인증 존재 여부, 필드 형식과 다음 제한을 확인한다.

| 항목 | 제한 |
| --- | --- |
| 본문 | 최대 16KiB |
| 시간 | 0~86,400,000ms의 정수 또는 `null` |
| 실패 횟수 | 0~1000의 정수 |
| 좌표 | 유한한 0~1 숫자 |
| 경로 | 최대 100개, 시간과 드래그 번호 순서 유지 |
| 드래그 번호 | 1~1000의 정수 |

처음 받거나 더 높은 순번이면 `201`로 반영한다. 같은 순번의 같은 내용과 과거 순번은 `200`으로 처리한다. 같은 순번의 다른 내용은 `409`, 없는 인증은 `404`, 형식 오류는 `422`, 본문 초과는 `413`이다.

인증 행을 잠그고 최신 스냅샷을 한 트랜잭션으로 반영한다. 늦게 도착한 과거 기록이 최신 값을 덮지 않는다.

## 저장과 조회

`captcha_interaction_summaries`에 인증당 한 행을 유지한다.

| 컬럼 | 용도 |
| --- | --- |
| `challenge_id` | 인증을 참조하는 기본키와 외래키 |
| `revision` | 최신 스냅샷 순번 |
| `metrics` | 시간, 실패 횟수와 경로를 담는 JSONB |
| `received_at` | 마지막으로 반영된 서버 수신 시각 |

사용자 이메일과 고객사 업무 내용은 이 요약에 복제하지 않는다. `python -m app.inspect_interactions`로 최근 기록을 조회한다. [백엔드 실행 설정](../backend/README.md)에 지정한 데이터베이스 연결을 사용한다.
