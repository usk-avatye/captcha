## 리뷰어가 판정 범위를 남긴 항목에 대한 결정
- Ruling: 이미지 정렬/crop은 본체의 실제 Chrome 캡처와 기존 1단계 소재 측정을 근거로 수용한다. 생성 소재가 원본 픽셀 조각과 같지 않다는 기존 한계는 유지한다. 잘못되면 소재 재측정·교체가 필요하다.
- Ruling: decode 재시도·Pointer Events·작은 화면은 이번 Chrome 통합 검증으로 확인한다. 다른 브라우저·실물 터치의 동작까지 보장하지 않는다. 다른 실행 환경에서는 별도 검증/수정이 필요할 수 있다.
- Ruling: 한 BMW 소재와 시도 중 creativeId/apiBaseUrl 고정이라는 기존 계약을 유지한다. 임의 소재/실행 중 입력 변경까지 확대하지 않는다. 확장 시 새 시도 key와 소재 메타데이터 검토가 필요하다.
- Ruling: 이번 입력은 승인된 Pointer Events 드래그다. 키보드 대체 인증은 추가하지 않는다. 따라서 키보드만으로 퍼즐을 완료할 수는 없다.
- Ruling: 서버 재시작 후 완료 UI 자동 무효화는 기존 설계대로 추가하지 않는다. 서버를 초기화한 시연에서는 탭을 새로고침해야 한다.
